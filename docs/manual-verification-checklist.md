# Lector AI — Chrome 手动验证清单

> 目的：在真实 Chrome 中加载 `dist/` 扩展后，逐项确认运行时功能是否正常。
> 用法：按顺序执行每一项；在「结果」栏勾选 ✅ / ❌；若 ❌，请粘贴控制台报错（F12 → Console）。

---

## 0. 前置准备（必读）

### 0.1 加载扩展
1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角开启 **「开发者模式」**
3. 点击 **「加载已解压的扩展程序」**，选择项目根目录下的 **`dist/`** 文件夹
4. 预期：扩展卡片「Lector AI - Smart Reading Assistant v0.3.0」出现，**无错误徽标**；工具栏图标显示品牌「L」图标（非通用拼图占位）

> ⚠️ 如果卡片上出现红色「错误」按钮，点击它并把错误信息回报 —— 这通常是 `dist` 未构建或 manifest 引用缺失。

### 0.2 BYOK 配置（关键，决定 AI 功能能否验证）

Lector AI 是 **BYOK（自带密钥）** 架构——**无后端、无账号**。所有 AI 功能需要你先在扩展里配置自己的 provider key：

1. 打开侧边栏（点工具栏「L」图标，或页面右下角浮动「L」按钮）
2. 点头部 **⚙️** 设置按钮
3. 选一个 provider（推荐 OpenRouter——一个 key 用所有模型），粘贴你的 API key
4. 点 **⬇ 拉取模型列表** 实时获取该账号可用模型，选一个（或手填模型 id）
5. 点 **Test connection**，预期返回 `✓ Connected. Model replied: "OK"`

**没有 key 时：** 聊天 / 摘要 / 翻译 / 解释 / 双语翻译这些 AI 功能会提示「请在设置中添加 API Key」并自动打开设置面板；离线功能（FAB / 页面抽取 / 高亮 / 词汇 / 会话库）不受影响，可独立验证。

下文每项标注「需 BYOK ✅/❌」。
